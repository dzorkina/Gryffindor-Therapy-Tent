# Терапевтический шатёр

Гриффиндору от Слизерина.

Бордовые бархатные шторы открываются на тёмно-зелёный стол. Нажатие на колоду вытягивает карту рубашкой вверх; нажатие на карту открывает льва. После переворота появляется кнопка «Вытянуть еще одну». Подпись и кнопка расположены по центру под обеими картами.

В колоде 21 изображение. Карты перемешиваются и не повторяются, пока не пройдена вся колода. При новом перемешивании первая карта отличается от предыдущей. Все изображения показываются целиком. Узор ткани регулируется в `styles.css`: `.tent::before`, значение `opacity` (сейчас `0.045`).

## Открыть на компьютере

Открой `index.html` в браузере. Установка программ или сборка не нужны. Для проверки через локальный сервер можно запустить из папки сайта:

```sh
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

Сайт работает и в подпапке репозитория: все ссылки на изображения относительные. Все картинки находятся внутри проекта; внешние шрифты, сервисы и библиотеки не нужны.

## Файлы

- `index.html` — вход и стол с картами.
- `styles.css` — оформление, адаптация и анимации.
- `script.js` — вытягивание, перемешивание и переворот.
- `assets/cards` — 21 карточка из присланного архива.
- `assets/card-back.webp`, `assets/deck.webp` — присланные рубашка и колода.
- `assets/curtains.webp` — созданные для проекта бархатные шторы.
- `assets/lion.png`, `assets/favicon-*.png`, `favicon.ico` — присланный лев с прозрачным фоном и варианты значка.

Сайт поддерживает телефон, планшет, компьютер, управление клавиатурой и системную настройку уменьшения анимаций. При уменьшении движения шторы и карты мягко растворяются вместо перемещения. Нажимать на колоду и карты можно клавишами Enter и пробел.
